# MateSolve



Aplicación web interactiva de matemática con un tutor virtual llamado **Ñioo**, que resuelve los ejercicios paso a paso explicando el procedimiento.



## Módulos



- Sistemas de ecuaciones 2x2 (método de Cramer)

- Aproximación de raíces: bisección, regla falsa y Newton-Raphson

- Interpolación de Newton hacia adelante, con diferencias finitas y números combinatorios

- Límites

- Derivadas

- Máximos y mínimos (primera y segunda derivada)

- Integral definida e indefinida

- Determinante 2x2

- Graficador de funciones

- Centro de práctica con ejercicios aleatorios y racha de aciertos



## Características



- Menú lateral y pizarrón donde se resuelven los ejercicios

- Teclado matemático desplegable con pestañas

- Historial de los últimos cálculos

- Explicaciones paso a paso de Ñioo



## Cómo usarlo



Abrir el archivo `index.html` en el navegador. Necesita conexión a internet para cargar las librerías.



## Tecnologías



HTML, CSS, JavaScript, [math.js](https://mathjs.org/) y [Chart.js](https://www.chartjs.org/).
